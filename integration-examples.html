🚀 Dashboard Embedding Examples

Example 1: Basic iframe Embedding

The simplest way to embed the dashboard - just an iframe with basic attributes.

<iframe src="embed.html" width="100%" height="600px" title="Fleet Dashboard" style="border: none;" ></iframe>

Example 2: iframe with Parent-Child Communication

This example demonstrates two-way communication between the parent page and the embedded dashboard using postMessage API.

// Listen for messages from dashboard window.addEventListener('message', function(event) { if (event.data.source === 'navixy-dashboard') { if (event.data.type === 'dashboard-ready') { console.log('Dashboard is ready!'); } } }); // Send messages to dashboard iframe.contentWindow.postMessage({ type: 'dashboard-config', theme: 'light' }, '*');

A production-ready example with a loading state and responsive design.

📚 Integration Tips

  • Performance: Use loading="lazy" attribute for off-screen iframes
  • Security: Configure CSP headers and X-Frame-Options appropriately
  • Responsive: Test on mobile devices and adjust heights accordingly
  • Communication: Always validate postMessage origins in production
  • Fallback: Provide a link to open the dashboard in a new tab if iframe fails
  • Build: Use npm run build to create production-ready files
  • HTTPS: Always serve over HTTPS in production for security
